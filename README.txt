How to use:
1. Open index.html in Chrome/Edge.
2. The supplied student data is already built into the demo, so you can click/use it immediately.
3. You can also upload a future Excel workbook. Each sheet is treated as a separate class/section.
4. Select 5th-A (or any section).
5. Enter only ABSENT students' S.No values.
6. Click Generate Attendance.
7. Present and Absent lists are calculated only for that selected section.
8. Download Present Excel, Absent Excel, or Complete Excel.
9. Complete Excel contains two sheets: Present and Absent.

Expected Excel columns:
S.No | I.D | Name | F/Name
The remaining date columns in your current monthly sheets are ignored for student-master import.

Important:
- 5th-A and 5th-B are completely separate.
- An S.No entered while 5th-A is selected is checked only against 5th-A.
- Duplicate S.No values are ignored.
- Unknown S.No values are shown as warnings.
- Works with many sections and 1500+ students.
- Browser-side app; no server/database is required.
